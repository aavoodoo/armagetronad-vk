BUGS
----

BUG 3 — Multi-viewport first-round flickering
  Status: Open
  Symptom: First round in multi-viewport mode flickers, then stabilizes.
  Cause: FBO creation overhead (8 GPU allocations on first multi-viewport frame).
  Fix: Pre-create viewport FBOs before the first frame.

BUG 5 — Cycle name/cockpit rendering in multi-viewport on macOS
  Status: Open
  Symptom: On macOS with 3-attachment FBOs (emissive variant), fonts/text are
  invisible. With 2-attachment FBOs (plain variant), fonts work but z-fighting
  returns.
  Cause: Unknown — the emissive fragment shader variant breaks font/text rendering
  through some mechanism specific to Metal/MoltenVK. Needs Metal GPU frame capture.
  Single viewport: fixed. iPad: works with 2-attachment FBOs.

BUG 11 — Cockpit widget positioning on widescreen
  Status: Matches original GL behavior (by design)
  The square viewport + Readjust(4/3 / aspect) system is identical to the original
  OpenGL code. On 16:9, top widgets (clock, FPS) may be off-screen — this is the
  same as the original game. Cockpit XMLs designed for 4:3 don't fully fill 16:9.
  Future: Add top-anchored widget positioning mode so cockpit XMLs can adapt to
  any aspect ratio.

BUG 12 — Shutdown validation warnings (2 remaining)
  Status: Mostly fixed (down from 10+ to 2)
  Two vkDestroySampler warnings from post-process system internal descriptor set
  ordering. Benign — GPU is idle, no data corruption. Fixing requires restructuring
  the PP Destroy() flow to separate descriptor pool from sampler destruction.

BUG 13 — Instanced cycle shadow not rendered
  Status: Open (minor visual)
  When USE_BATCHED_CYCLES is enabled (default), the cycle shadow quad is not
  rendered because the instanced path skips the legacy shadow draw code.
  Fix: Submit shadow quads separately (they're simple textured quads, not models).

NOTES
-----

- Batching limitation: rStaticMesh (cycle bodies) must flush immediately because
  vertices are in model space and need the per-cycle transform at draw time.
  Only wall geometry (world-space vertices) benefits from batched flushing.
  With instanced rendering enabled, cycle models bypass this limitation entirely.
- Guard PushMatrix/PopMatrix added around gCycle::Render() to prevent cross-cycle
  matrix stack contamination. No actual stack underflow detected in testing.
- RemoveDirectoryRecursive on iOS uses NSFileManager (rScreenIOS.mm).
- Moviepack settings saved to Documents/moviepack_saved_settings.cfg.
- MSDF moviepack shader uses msdfgen-recommended screenPxRange calculation
  with fwidth(texCoord) for safe derivatives (not fwidth(d) which causes NaN
  on MSDF median discontinuities).
- Wall rendering: persistent UV bounds prevent texture matrix pops. Line vertex
  caching avoids per-frame heap allocation. Fingerprint-based skip-conversion
  was attempted but reverted (boundary segments always change, causing stale data).
