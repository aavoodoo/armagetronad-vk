Known Issues & Remaining Work — 2026-04-26
============================================

BUGS
----

BUG 3 — Multi-viewport first-round flickering
  Status: Open
  Symptom: First round in multi-viewport mode flickers, then stabilizes.
  Cause: FBO creation overhead (8 GPU allocations on first multi-viewport frame).
  Fix: Pre-create viewport FBOs before the first frame.

BUG 5 — Cycle name/cockpit rendering in multi-viewport on macOS
  Status: Open
  Symptom: On macOS with 3-attachment FBOs (emissive variant), fonts/text are
  invisible. With 2-attachment FBOs (plain variant), fonts work but z-fighting
  returns.
  Cause: Unknown — the emissive fragment shader variant breaks font/text rendering
  through some mechanism specific to Metal/MoltenVK. Needs Metal GPU frame capture.
  Single viewport: fixed. iPad: works with 2-attachment FBOs.

BUG 11 — Cockpit widget positioning on widescreen
  Status: Matches original GL behavior (by design)
  The square viewport + Readjust(4/3 / aspect) system is identical to the original
  OpenGL code. On 16:9, top widgets (clock, FPS) may be off-screen — this is the
  same as the original game. Cockpit XMLs designed for 4:3 don't fully fill 16:9.
  Future: Add top-anchored widget positioning mode so cockpit XMLs can adapt to
  any aspect ratio.

BUG 14 — About screen blank on first visit (intermittent)
  Status: Open
  The SwapBuffers/rRenderFrame nesting causes the first display to sometimes
  render into a stale frame. Subsequent visits work. Root cause: SwapBuffers
  calls BeginFrame+EndFrame which creates an empty frame overwriting the
  rendered content.

BUG 15 — Flashing when switching moviepacks mid-game
  Status: Open
  Switching between moviepacks during gameplay can cause rapid flashing between
  game and menu frames. Workaround: restart the game after moviepack change.
  Cause: ReloadShaders deferred to next BeginFrame interacts with the menu's
  render frame lifecycle.

NOTES
-----

- Shader hooks: uCameraPos (normalMatrix[2]) and uArenaBBox (normalMatrix[3])
  available for unlit hooks via push constants. For lit hooks (cycles),
  normalMatrix carries the actual normal matrix + materialDiffuse.
- Android keyboard offset: only applied when explicitly requested (chat/console),
  not for generic menu text input. Desktop platforms always return 0.
- All moviepack leaks from Apple's Vulkan driver (vk_cmd_enqueue_CmdBindDescriptorSets)
  — not application code. Command pool destroyed last to minimize.
